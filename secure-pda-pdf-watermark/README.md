SECURE PDA PDF WATERMARK

DESCRIPTION
Generates personalised watermarked PDF downloads for protected
PDF files managed by Prevent Direct Access (PDA) Gold.

SHORTCODE

[secure_pda_pdf id="17977"]

PARAMETERS

id
Required. The WordPress Media Library attachment ID of the PDF.

watermark
Optional. Main watermark text. Default: PERSONAL COPY.

show_name
Optional. Display the WordPress username. Default: 1.

show_date
Optional. Display the download date. Default: 1.

REQUIREMENTS

- WordPress
- PHP 8.1 or later
- Prevent Direct Access Gold
